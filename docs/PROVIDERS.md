## Evidence and limits

The current BimpeAI Custom API guide says integrations can be configured through its SDK/API, but channels such as telephony/voice are connected on the dashboard Deploy screen; the API can list channel connections but cannot create or remove them. The deployment guide says inbound telephony uses BimpeAI's Telephony card, a number linked under Team settings, and a voice profile configured under Settings → Voice. In the authenticated account, the agent has no assigned number and no channel has been connected. The phone-number screen's BYO SIP controls show generic SIP credential flow, not a Temlio-specific route. Current public materials therefore do not prove a Temlio-backed Bimpe telephony path.

The authenticated Bimpe voice selector directly lists Mary, Osagie, Remi, and Umar as YarnGPT voice options. Mary was saved for the LightLine agent. YarnGPT's standalone API docs describe a separate TTS API, but LightLine does not need a direct API integration for the selected Bimpe voice.

## Workflow assignment recovery

Before a dedicated agent was created, saving the new `LightLine Complaint Intake` workflow affected the selected existing `Yusuf Saheed's Agent`. Bimpe's saved-workflow toast said edits apply to all agents using it; after the LightLine agent was created the workflow showed two agents using it. Workflow ID from the dashboard URL: `cmus5pyvr02sipy87kqncsgbu`. The original Yusuf agent had no voice profile and there were no other existing account agents/workflows. The dashboard's Settings → Agent page has no workflow control; Playground's “Change workflow” opens the workflow catalogue, and no unassign option was visible. Current official docs say `workflow_id` is an agent update field but do not document whether `null` detaches it. No unsupported API request, deletion, or further edit was attempted. The existing agent's workflow assignment therefore remains a known side effect requiring provider/owner correction. The LightLine agent is separately present in Development and has Mary YarnGPT selected. No credentials or browser storage were inspected.
